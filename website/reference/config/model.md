# `model.ossie.yaml`

The semantic model, in [Apache Ossie](https://ossie.apache.org/) 0.2. tidepool
also accepts the wrapped shape of Ossie 0.1.1 (`semantic_model:`). See
[the model](/project/the-model) for how the parts fit together.

Expressions are SQL. tidepool reads the `OSSIE_SQL_2026` dialect, and
`ANSI_SQL` when the expression has no `OSSIE_SQL_2026` version.
